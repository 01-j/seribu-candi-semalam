# Seribu Candi Semalam — Prototipe

Prototipe digital board game kooperatif **Seribu Candi Semalam** (2–4 pemain, satu perangkat).

▶️ **Main:** buka halaman GitHub Pages repo ini, atau buka `index.html` langsung di browser.

## Cara main singkat
- Tim bersama-sama membangun 16 ubin (termasuk Ubin Gerbang) di papan 7×5 sebelum fajar.
- Setiap pemain memegang 2 ubin. Pasang satu ubin per giliran; semua sisi yang bersentuhan harus bermotif sama (Kawung, Tumpal, Teratai, Awan). Ubin tidak diputar.
- Kalau tidak ada ubin di tangan yang bisa dipasang, buang satu ke Bayang — Penanda Obor maju satu langkah.
- **Kalah** jika Penanda Obor mencapai langkah ke-6 (fajar), atau tumpukan dan semua tangan habis sebelum 16 ubin.

Progres permainan tersimpan otomatis di browser (localStorage).

## Deploy ke GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
